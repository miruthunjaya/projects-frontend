# Interactive Valentine's Day Card 💘

A playful and interactive Valentine's Day card with animations and responsive design. The card asks a series of questions with fun animations when the user responds.

## Features

- Name personalization
- Heart pulse animation
- "No" button dodging effect
- Multiple rejection messages
- Confetti celebration effect
- Mobile-responsive design
- Smooth animations and transitions

## Technologies Used

- HTML5
- CSS3 (Animations, Flexbox)
- JavaScript (DOM Manipulation)
